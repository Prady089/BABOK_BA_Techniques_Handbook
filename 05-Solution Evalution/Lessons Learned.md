# Lessons Learned (BABOK® Technique)

## What This Technique Is

Lessons Learned captures **insights from past initiatives** to improve future performance.

It focuses on:
- What worked well
- What did not work
- Why outcomes occurred
- How to improve next time

---

## Why This Technique Exists

Organizations repeat mistakes when learning is informal or lost.

BABOK includes Lessons Learned to:
- Promote continuous improvement
- Reduce repeated errors
- Improve delivery maturity

---

## When to Use Lessons Learned

- At project closure
- After major milestones
- Following incidents or failures
- During retrospectives

---

## How Lessons Learned Are Captured

1. Facilitate structured discussion
2. Capture observations objectively
3. Identify root causes
4. Define improvement actions
5. Store lessons in a shared repository

---

## Real-World Example (Banking / IT)

After a data migration:
- Lesson: Incomplete source data profiling caused delays
- Improvement: Mandatory profiling checklist for future projects

---

## Common Mistakes

- Turning lessons learned into blame sessions
- Capturing lessons but not applying them
- No ownership for improvements

---

## Key Takeaway

Lessons Learned convert experience into **organizational knowledge**.
